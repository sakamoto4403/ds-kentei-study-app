# Codexへの追加プロンプト：教科書モード

```
このリポジトリ（pmp-study-app）に、新しい閲覧専用モード「教科書モード」を
追加します。既存機能・データスキーマは一切変更しません。

まず docs/BRIEF_ADDENDUM_textbook_mode.md を通読してください。

【現状確認】
実装に入る前に、現在の app.js を確認し、以下を私に報告してください。
- 章一覧・章カードの実装箇所（ボタンをどう追加するか把握するため）
- 演習画面で「正解の選択肢を強調表示する」際に使われているCSSクラス名
  （教科書モードでも同じ見た目に揃えるため、可能なら流用する）
- ビュー切り替えの実装方法（新規ビューをどう追加すればよいか）

【実装範囲】
docs/BRIEF_ADDENDUM_textbook_mode.md の §2〜§3 に従い、以下を実装してください。

1. 新規ビュー「教科書モード」を追加
   - トップ画面ヘッダーに「教科書モード」ボタンを追加し、章選択後にその章の
     教科書モード画面を開けるようにする
   - 各章カードに「教科書で読む」ボタンを追加し、その章の教科書モード画面へ
     直接遷移できるようにする

2. 画面表示（§2.2）
   - 章内の全問題をid昇順で連続表示。1問ごとに問題文・選択肢・正解の強調表示・
     解説を表示し、区切り線を入れる
   - 選択肢は非インタラクティブ（クリックしても何も起きない）

3. 章内目次（§2.3）
   - 問題番号へジャンプできる簡易ナビゲーションを章の先頭に設置
   - ページ末尾に「トップに戻る」「次の章を読む」（最終章では非表示）を設置

4. 学習記録への影響なし（§2.4、最重要）
   - 教科書モードを開いても records / chapterStatus / resumePointer を
     一切更新しないこと。既存の演習・復習ロジックの関数を誤って呼び出さないよう、
     完全に独立した描画関数として実装すること

【厳守事項】
- 既存のlocalStorageスキーマ、演習画面、復習モード、サマリー画面、
  データ管理画面、解答履歴マトリクス表のロジックは変更しないこと
- 新しいライブラリ・フレームワークは追加しないこと（Vanilla JSのみ）
- questions.sample.json は動作確認に使用してよいが、変更しないこと

【完了時の報告】
- 変更・追加したファイルの一覧
- docs/BRIEF_ADDENDUM_textbook_mode.md §4の完成の定義を上から順に検証した結果
- 教科書モードを開いた前後で、学習記録（章の進捗・正答率）が変化していないことの確認結果
```
