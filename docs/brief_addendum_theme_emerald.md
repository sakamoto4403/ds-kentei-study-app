# BRIEF追補：テーマカラーをエメラルドグリーンに統一

> 本書は `docs/BRIEF.md` の追補である。デザイン（配色）のみの変更であり、
> データスキーマ・機能・画面構成には一切変更を加えない。

---

## 1. 目的

アプリ全体のアクセントカラーを**エメラルドグリーン系**に統一する。現状は特定の配色指定がなく実装側の裁量になっているため、本書で色を確定させる。

## 2. カラーパレット（確定）

CSSカスタムプロパティとして`style.css`の`:root`に定義し、色のハードコードを避けてこれらの変数経由で使用する。

```css
:root {
  --color-primary: #10b981;        /* エメラルドグリーン（メイン） */
  --color-primary-dark: #047857;   /* 濃色（ホバー・押下時、テキスト用） */
  --color-primary-light: #d1fae5;  /* 薄色（背景・バッジ用） */
  --color-primary-lighter: #ecfdf5;/* さらに薄い背景用 */

  --color-danger: #ef4444;         /* 不正解・警告（赤系、既存踏襲） */
  --color-danger-light: #fee2e2;

  --color-text: #1f2937;
  --color-text-muted: #6b7280;
  --color-border: #e5e7eb;
  --color-bg: #ffffff;
}
```

- 不正解・削除・警告系の赤（`--color-danger`）は変更しない（正誤の区別を色だけに依存させないため、既存の赤系のまま維持）。
- 上記の変数名・値は確定とする。既存CSSに変数定義が無い場合は新規追加し、既存CSSに近い変数名が既にある場合は値だけこの色に合わせて変更する（変数名は既存を優先してよいが、値は本書のとおりにする）。

## 3. 適用箇所（既存機能を洗い出し、色のみ変更する）

以下はすべて**既存の要素**であり、新規要素の追加ではない。色の指定のみを変更する。

| 箇所 | 変更内容 |
|---|---|
| 全体のボタン（「演習を始める」「解答する」「次の問題へ」等） | 背景色を`--color-primary`、ホバー時`--color-primary-dark` |
| 演習画面：正解の選択肢ハイライト | 背景`--color-primary-light`、枠線・チェックマーク`--color-primary-dark`（不正解の選択肢は赤系のまま） |
| 教科書モード：正解の選択肢ハイライト | 演習画面と同一の配色に統一（`docs/BRIEF_ADDENDUM_textbook_mode.md`参照） |
| 章ステータスバッジ「完了」 | 背景`--color-primary-light`、文字`--color-primary-dark` |
| 章ステータスバッジ「進行中」 | 中間色として`--color-primary`を薄めた別トーンでよいが、「完了」バッジと視覚的に区別できること |
| 解答履歴マトリクス表：○（正解）セル | 文字色または背景に`--color-primary-dark`系（`docs/BRIEF_ADDENDUM_history_matrix_v2.md`参照） |
| リンク・アクセント文字（「もっと見る」等） | `--color-primary-dark` |
| トップ画面ヘッダーの全体正答率・進捗表示 | アクセント数値部分に`--color-primary-dark` |
| PWAの`theme_color`（`manifest.json`） | `#10b981`に変更 |
| iOS用ステータスバー（`apple-mobile-web-app-status-bar-style`） | 既存の`default`のままでよい（色変更に伴う挙動変更は不要） |

## 4. 変更しないもの

- レイアウト・余白・フォントサイズ・画面構成・機能ロジックは変更しない。
- 不正解・エラー・警告表示の赤系配色は変更しない。
- 背景の白・グレー系（本文・境界線）は上記`--color-text` `--color-border`等の中立色のまま維持する。

## 5. 完成の定義

- [ ] `style.css`にエメラルドグリーン系のCSSカスタムプロパティが定義されている
- [ ] 表3の全箇所が新しい配色に統一されている（既存機能の見た目以外は変化していない）
- [ ] 不正解・警告表示の赤系は変更されていない
- [ ] `manifest.json`の`theme_color`が`#10b981`になっている
- [ ] PC・iPhoneの両方で配色が正しく反映されていることを目視確認
- [ ] 色のコントラスト比が読みにくくなっていないか目視確認（特に薄い背景色に薄い文字色を重ねていないか）
