## 1. 色について（前提の共有）

「ティファニーブルー」はTiffany & Co.が色彩商標「1837 Blue」として登録しており、正確な色は一般公開されていない。世間で広く使われている近似色として `#0ABAB5` を採用する（個人利用アプリのため商標上の制約は問題にならないが、参考として付記する）。

## 2. カラーパレット（確定・エメラルド版から差し替え）

```css
:root {
  --color-primary: #0abab5;        /* ティファニーブルー（メイン） */
  --color-primary-dark: #078e8a;   /* 濃色（ホバー・押下時、テキスト用） */
  --color-primary-light: #d3f3f1;  /* 薄色（背景・バッジ用） */
  --color-primary-lighter: #eefbfa;/* さらに薄い背景用 */

  --color-danger: #ef4444;         /* 不正解・警告（赤系、変更しない） */
  --color-danger-light: #fee2e2;

  --color-text: #1f2937;
  --color-text-muted: #6b7280;
  --color-border: #e5e7eb;
  --color-bg: #ffffff;
}
```

- 変数名は`docs/BRIEF_ADDENDUM_theme_emerald.md`と同一のまま、**値のみ**をこの表のとおりに変更する。
- 既にエメラルドグリーンで実装済みの場合、`#10b981`系の値を検索し、上記の値へ一括置換する形で対応してよい。
